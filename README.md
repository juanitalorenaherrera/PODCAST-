# ☕ Código y Café Entre Amigos

Bienvenido al sitio web oficial de **Código y Café Entre Amigos**, un podcast creado por un grupo de amigos apasionados por la tecnología, el desarrollo de software y las buenas conversaciones.

Nuestro objetivo es compartir experiencias, debatir sobre las últimas tendencias tecnológicas y crear una comunidad donde aprender sea tan agradable como disfrutar una buena taza de café.

---

## 📸 Vista previa

En este sitio encontrarás:

## ⚙️ Instalación

1. Clona el repositorio.

```bash
git clone https://github.com/usuario/codigo-y-cafe.git
```

2. Entra al proyecto.

```bash
cd codigo-y-cafe
```

3. Abre el archivo **index.html** en tu navegador.

No es necesario instalar dependencias.
